# Mr. Router

تطبيق أندرويد للتحكم في راوترات ZTE (WE): عرض الأجهزة المتصلة، إيقافها لمدة أو لحد ما تفكها، مواعيد يومية، وإعدادات الواي فاي.

## التنزيل
آخر نسخة دايماً هنا: **[Releases ← Latest](https://github.com/rawyym-dot/mr-router-app/releases/latest)** ← نزّل ملف `MrRouter-xx.apk` وثبّته.

بعد أول تثبيت، التطبيق بيبلّغك لوحده بأي تحديث جديد وبيحدّث نفسه بضغطة.

الصفحة دي فيها ملفات التطبيق بس. باسوردات الراوترات بتتحفظ على كل موبايل لوحده ومش موجودة هنا.
